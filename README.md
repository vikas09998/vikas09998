### 🤖 Next-Gen DevOps: GenAI, MCP & RAG Agents

I actively integrate modern AI architectures into enterprise platform engineering:

* 🔌 **Model Context Protocol (MCP) Servers:** Building standardized MCP tool execution servers that safely connect LLMs to cloud APIs, allowing AI agents to query infrastructure telemetry, diagnose Kubernetes pod anomalies, and inspect drift without exposing root credentials.
* 🧠 **RAG-Powered Runbook Assistance:** Architecting internal SRE knowledge agents backed by vector search (Qdrant/Chroma) over living ADRs, incident post-mortems, and runbooks for instant on-call troubleshooting.
* 🛡️ **Autonomous Drift & Policy Triage:** Implementing agentic workflows that inspect Terraform drift alerts, compare them with active change requests, and draft automated PR fixes.
* ⚙️ **LLMOps & Platform Infra:** Deploying scalable vector databases, prompt governance frameworks, and hardened AI inference workloads on Kubernetes.

* **Enterprise Landing Zones (CAF):** Structured tenant management group hierarchy separating Platform subscriptions (`Identity`, `Management`, `Connectivity`) from Workload subscriptions (`Dev`, `UAT`, `Prod`).
* **Hub-and-Spoke Connectivity:** Centralized Azure Firewall / NVA packet inspection, forced UDR routing, and Private Endpoints with zero internet exposure for databases.
* **Continuous DevSecOps:** Strict trunk-based development with branch policies, automated security scans, Infracost budget estimation, and scheduled drift detection.
* **Cloud FinOps Excellence:** Systemic rightsizing, automated start/stop of non-prod workloads, RI/Savings Plans, and granular log ingestion filtering.
